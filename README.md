# Vue-Navarro-Chacon
# Gestor de Lecturas (Vue 3)

**Autores:** David Navarro Muñoz y Antonio Chacón Durán

## Tema y funcionamiento
Aplicación web desarrollada en React para gestionar gastos diarios. Permite añadir gastos con concepto, importe y categoría, filtrar por categoría, calcular el total gastado en tiempo real, eliminar registros y guardar los datos automáticamente en el navegador mediante `localStorage`.

## Cómo arrancar el proyecto
1. Clonar el repositorio:
   `git clone https://github.com/antoniochaconc/vue-navarro-chacon.git`
2. Instalar las dependencias:
   `npm install`
3. Arrancar el servidor de desarrollo:
   `npm run dev`
