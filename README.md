## Cómo arrancar el proyecto
1. Clonar el repositorio:
   `git clone https://github.com/antoniochaconc/vue-navarro-chacon.git`
2. Instalar las dependencias:
   `npm install`
3. Arrancar el servidor de desarrollo:
   `npm run dev`
