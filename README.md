# Vue-Navarro-Chacon
# Wiki_reseña de Videojuegos(Vue 3)

**Autores:** David Navarro Muñoz y Antonio Chacón Durán

## Tema y funcionamiento
Aplicación web desarrollada en Vue 3 que funciona como una wiki personal de reseñas de videojuegos. Permite consultar fichas de juegos con su plataforma, género, valoración numérica y análisis, buscar por título o filtrar por plataforma, añadir nuevas reseñas mediante un formulario validado, marcar juegos como imprescindibles/favoritos y guardar todos los datos automáticamente en el navegador mediante `localStorage`.

## Cómo arrancar el proyecto
1. Clonar el repositorio:
   `git clone https://github.com/antoniochaconc/vue-navarro-chacon.git`
2. Instalar las dependencias:
   `npm install`
3. Arrancar el servidor de desarrollo:
   `npm run dev`
